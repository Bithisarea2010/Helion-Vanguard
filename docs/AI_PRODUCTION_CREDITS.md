# AI-assisted production history

Helion Vanguard is directed and owned by Bithisarea / Original Games. This
repository records an AI-assisted production history at the request of the
project owner:

1. Early iteration and foundation work used **Fable 5**.
2. Subsequent implementation passes used **GPT-5.6 Sol**.
3. A later refinement pass used **Opus 5**.
4. Version **1.3.0** was completed with **Astra**.

These tools assisted with implementation, debugging, visual and audio asset
generation, documentation, testing, and release preparation. Creative
direction, repository ownership, publishing authority, and final decisions
remain with the project owner.

This credit describes the production workflow. It does not imply endorsement,
affiliation, or authorship by any model provider.
