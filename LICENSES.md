# Helion Vanguard — Licences and Attributions

Helion Vanguard is an original game. All code, 3D models, missions, visual
effects, original music loops and sound effects were created specifically for
this project. The optional playlist consists of project-owner-supplied tracks
documented below. No assets were extracted from or copied from any commercial
game.

## Game code and original content

- All GDScript code, shaders, mission scripts and design: original work,
  created for this project (© 2026 Original Games).
- All spacecraft, station, cockpit and asteroid **meshes**: procedurally
  modelled in Blender specifically for this game (original work). The Blender
  source files and generator scripts are included under `blender_src/`.
- All **sound effects** and the original menu/combat loops: procedurally
  synthesised with the included Python program `tools/gen_audio.py`.
- The optional randomized background playlist also includes six MP3 files
  supplied by the project owner: Warp Speed Rush, Neon Dogfight, Orbit
  Assassin, Hyperdrive Conflict, Frontier Combat Drive and Stellar Vanguard.
  Their public redistribution and attribution rights must be confirmed by the
  project owner before using this repository for a public release.
- Application icon: generated by the included original program
  `tools/gen_icon.py`.

## Original quality-production additions — 1.3.0, 2026-09-13

No external asset or plugin was downloaded or added in this pass. The new
Vanguard, Peregrine, Aegis and Relay 07 meshes and all nine `hv_*.wav` sounds
were created for this project and are covered by its MIT LICENSE. Their source
is `blender_src/hero_fleet.py`, `blender_src/relay_foundry.py` and
`tools/quality_audio.py`; editable Blender files are retained. There is no
external source URL for original project work. Exact files and usage are in
`assets/manifest.json`.

Existing local tools used, without installation or paid services:

- Godot 4.7.2 official, MIT; https://godotengine.org/license/ — editor, Metal
  Forward+ playtests and packaged runtime. The local build includes the actual
  compiled runtime's MIT and third-party notices under `Licenses/Godot.txt`.
- Blender 5.2.0 LTS, GPL; https://www.blender.org/about/license/ — offline mesh
  generation, glTF export and separate studio previews. Blender is not bundled.
- NumPy bundled with Blender, BSD-3-Clause;
  https://numpy.org/doc/stable/license.html — original waveform synthesis;
  NumPy is not bundled in the game.

The pre-existing NPGameDev Godot MCP Toolkit was preserved. It is excluded
from the game resource pack, along with local MCP configuration. The existing
owner-supplied MP3 redistribution limitation above remains unchanged.
